# 협동 미션 비즈니스 룰

## 1. 진행 단계

협동 미션의 `currentStep`은 `1`, `2`, `3`만 사용한다.

단계 의미:

- `1`: 초대
- `2`: 역할 분배
- `3`: 사진 인증

미션 완료는 별도 step으로 취급하지 않는다.

미션 완료 여부는 `currentStep`이 아니라 `missionProgressStatus`로 판단한다.

## 2. 초대 단계

방장이 협동 미션을 시작하면 협동 미션 진행도를 생성하고 `currentStep`을 `1`로 저장한다.

방장은 참여자로 함께 생성한다.

팀원은 팀 단위 초대 URL을 통해 참여한다.

## 3. 역할 분배 단계

`currentStep`을 `2`로 변경하면 역할 분배 단계로 이동한다.

역할 카드 배정 자체는 프론트에서 확정해서 백엔드로 전달한다.

백엔드는 전달받은 역할 배정 정보를 검증하고 저장한다.

모든 역할 카드는 정확히 한 번씩 배정되어야 한다.

## 4. 사진 인증 단계

`currentStep`을 `3`으로 변경하면 사진 인증 단계로 이동한다.

각 참여자는 배정받은 역할 카드에 맞춰 사진 인증을 진행한다.

역할 인증이 완료되면 해당 역할 진행도의 상태를 `COMPLETED`로 변경한다.

모든 역할 인증이 완료되면 협동 미션 진행도의 `missionProgressStatus`를 `COMPLETED`로 변경한다.
